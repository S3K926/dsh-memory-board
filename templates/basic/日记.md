# 日记（骨架）

> 【占位】这是新设备铺底时写的骨架，**不是谁的记忆**：下面一条日记都没有。
> 历史要靠回流包导入，或者在记忆面板的「日记」页里手动新增。
> 文件行尾是 CRLF、编码是 UTF-8 无 BOM —— 档案里的脚本只认这个口味，别改成别的。

## 元信息

| 字段 | 值 |
|---|---|
| owner_character | 【占位】 |
| owner_aliases | 【占位】 |
| standalone | true |
| character_version | 【占位】 |
| diary_version | 3.0 |
| format_version | 1.1（Markdown 版） |
| last_diary_seq | 0 |
| total_count | 0 |
| privacy | 【占位】 |
| retention | 保留全部日记，只增不减 |

**版本规则（骨架自带，写下来免得忘）**：`diary_version` 的**第二位只在总篇数为 2 的倍数时 +1**
（例如 8 篇 → 1.3、10 篇 → 1.4），奇数篇不动；格式调整时第三位 +1。
新增一条日记时，面板按这条规则自动升位，不用你管。

## 写法

- 一条日记的标题行形如：`### #N ｜ YYYY-MM-DD ｜ HH:MM ｜ 【设备】 ｜ full`。
  **早期条目可以只有四段**（没有设备那一段），面板两种都认。
- 标题里的分隔符是**全角 ｜**。
- 六个字段名各占一整行、只有 `**名字**`，正文从下一行开始，字段之间空一行：
  `event_description` / `user_mood` / `mood_tags` / `notes` / `lively_details` / `mood_tail`。
- **不是每条后面都有 `---`**，所以切条目一律按标题行来。
- 条目按序号升序排，新的加在**末尾**；序号只增不减。
